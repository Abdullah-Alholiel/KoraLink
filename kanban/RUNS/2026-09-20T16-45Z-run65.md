### Commit `7e364a8` — feat(pwa): push locale re-sync (P2-76b / P2-83)

- Stale-locale fix: pushes kept the subscribe-time language after an ar/en switch. Hook
  re-upserts the idempotent subscribe endpoint when the persisted `kl.push.syncedLocale`
  marker drifts from the active locale (URL-driven locale switches REMOUNT the hook — a
  prev-value ref never observes the change; localStorage is the trigger).
- Failures → Sentry `pushLocaleSync`, marker not advanced (retries next mount); subscribe
  seeds the marker; unsubscribe clears it. Zero API changes.

### Commit `3d1840d` — feat(chat): cursor pagination + latest-window fix (P1-3 remaining)

- API: `GET /matches/:id/messages` optional `before` (message-id cursor; validated PK
  anchor — forged/unknown → 404, cross-match → 404) + `limit` (clamped 1..100). **Bare
  chronological array contract kept.** **Latest-window fix:** the no-cursor default now
  returns the NEWEST page (DESC probe reversed to ascending) — the old `ASC LIMIT 50`
  returned the EARLIEST 50 messages ever, so any 50+ message chat rendered a stale window
  where new messages vanished on reload. Uses keyset index `match_messages_match_created_idx`
  (migration 0014 — no new migration).
- PWA: `useMatchChat` probes `limit=51` (full page ⇒ hasMore), `loadOlder` pages backward
  with dedup; ChatSheet localized load-older strip (`chatSheet.loadOlder` en+ar); auto-scroll
  re-keyed from `messages.length` to the last message id (prepends no longer yank scroll);
  Array.isArray contract-drift guards on both fetch paths.
