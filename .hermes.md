# KoraLink — Workspace Quick Reference

Stack: **Turborepo + npm** monorepo (npm@10.8.1 workspaces). Two apps:
- `apps/api` — NestJS + Drizzle ORM + PostgreSQL + JWT cookie auth + WebSockets + Unifonic OTP.
- `apps/player-pwa` — Next.js App Router PWA + Tailwind + Zustand + i18n (ar/en) + offline (sw.js/manifest.json).

## Hard gate
`npm run build` (or `turbo run build` from root) must pass with zero errors before any declaration of "done." Build verification is non-negotiable — never claim success without actual terminal output showing it.

## Before any work
1. `gh auth status` must show "Logged in to github.com as ..." — stop and alert if not.
2. `git status` must show a clean working tree — commit or stash any drift first.
3. `npm --version` ≥ 10.x, `node --version` ≥ 20.x.

## Key files
- `AGENTS.md` at the monorepo root — binding coding standards (generated by Phase 1, enforced thereafter).
- `docs/skills/koralink-ui-standards.md` skill — design system for all UI work (generated by Phase 2, load before any screen).
- `lib/fetcher.ts` — canonical API client for the PWA (extend, don't replace).
- `store/useAppStore.ts` — Zustand client state (extend with new slices).
- `apps/api/src/common/guards/jwt-cookie-auth.guard.ts` — the auth guard for all protected endpoints.
- `apps/api/src/database/schema.ts` — Drizzle schema (add tables/migrations here).

## Autonomy & Workflow
I work within the 4-Gate Software Factory loop. 
1. Gate 0: Retrospective - Review past commits for tech debt.
2. Gates 1-3: Write specs to `docs/plans/<feature>/`. No implementation code is written until Gate 3 (Program Design) is approved.
3. Gate 4: Vertical Slices - Build end-to-end tracer bullets, then real logic. 
Hard gate remains: `turbo run build` must pass with zero errors before claiming any slice is done. I compact context into the `docs/plans/` markdown files at every gate boundary.
